# Security

Use **Security → Report a vulnerability** on this repository when the form is
available. If you cannot access it, open an issue asking for a private reporting
channel. Keep vulnerability details out of that issue.

In the private report, include the commit you used, what happened, the impact,
and steps to reproduce it. Remove credentials, private repository URLs and
customer data from examples and logs. Ordinary bugs can be reported in Issues.

Workspace installs and runs Python code from the repositories in your catalog.
Review those sources and their dependencies before running an unfamiliar project.
A source commit fixes the Git input; pip still resolves package dependencies
during installation.
